# One-Sentence Absurd Invention Pitch — The Apologizer

My entry for the make.fun competition "One-Sentence Absurd Invention Pitch": a program that writes a single sentence pitching a ridiculous invention that fixes a tiny everyday annoyance.

**The pitch:** *The Apologizer: a self-scolding alarm clock that says sorry for waking you, then snoozes itself out of guilt so you can sleep five more minutes in peace.* (153 characters, one sentence)

Why it works: most alarm clocks bully you awake — this one feels guilty about it. The fix is clever because the invention punishes itself, not you: it apologises, then snoozes itself out of guilt, so the annoyance (being woken up) dissolves into five more minutes of peace.

## Run it

```sh
python3 main.py
```

This writes exactly the sentence above (153 characters, no trailing newline) to `/output/entry.txt`.
